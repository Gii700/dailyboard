# DailyBoard

DailyBoard adalah dashboard produktivitas harian yang dibuat menggunakan HTML, CSS, dan JavaScript murni.

## Fitur
- Menambah tugas
- Menghapus tugas
- Menandai tugas selesai
- Filter tugas
- Edit tugas
- Catatan cepat
- Penyimpanan localStorage
- Widget kutipan
- Widget cuaca
- Drag and drop
- Dark mode
- Pencarian tugas

## Struktur File

DailyBoard/
├── index.html
├── style.css
├── script.js
    └── ntut/
    ├── tugas.js
    └── api.js
    └── storage.js
    └── catatan.js
## Teknologi

- HTML
- CSS
- JavaScript
- LocalStorage
- Fetch API
- ES Modules

## Deployment

Project di-deploy menggunakan GitHub Pages / Netlify.
